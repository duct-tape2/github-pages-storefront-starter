# Template Quality Review: 2026-10-30

**Scope:** every file in the repo at `8e978a1` (seed): README, CHECKLIST, LICENSE, issue templates, FUNDING, `docs/index.html`, the hero image, and `examples/free-storefront-lite.html`.
**Method:** I read every file, rendered pages in headless Chromium at 375×812 and 1280×900, computed text contrast for every text node in `main` and `footer`, used keyboard Tab order, and ran the new `scripts/check_site.py` against the original and updated pages.
**Branch:** `claude/template-quality-20261030`

**Severity:** High = buyers are misled or blocked, or the requested template defaults are missing. Medium = noticeable quality, accessibility, or maintenance problem. Low = polish.
**Status:** Fixed = done on this branch. Owner = left unchanged because it involves price, promise, legal, or brand content, and needs the owner's call. Info = no action needed.

- The "Done For You" paragraph is now the description in a **$99** price card, and its five links are that card's buttons. A **Free** card reuses the README's opening sentence and the existing template/ZIP links. The cards give the Offer JSON-LD visible text to match.

I wrote only the question wording. This is an owner decision: delete the `faq` entries in `storefront.json` to remove the section and its FAQPage JSON-LD.

- The offer name "Buyer-ready repo page" comes from the existing footer link text.
